# Handtrader

Cubes 3D à attraper avec la main, via la webcam (MediaPipe + Three.js).

- `index.html` : version ordinateur (gravité, cubes solides empilables, lancer).
- `ar.html` : version AR pour smartphone (caméra arrière, pose des cubes sur une surface).
- `serve-https.py` : serveur HTTPS local pour tester sur un téléphone.
